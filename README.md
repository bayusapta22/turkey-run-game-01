**Turkey Run** — Pip the turkey escapes becoming Thanksgiving dinner. Outrun
Farmer Bram for 2000 m through the farmyard, the cornfield and the kitchen:
dodge hay bales, fences, runaway pumpkins, falling carving knives and the
swinging cleaver, stay off the glowing oven grates, grab corn (it slows the
farmer down), golden feathers and chili dashes. Three lives, a HUD with
score, distance, hearts and a farmer-danger meter, title / caught / escaped
screens with restart. All art is drawn in canvas and all sound is synthesized
with WebAudio — the game loads and plays fully offline from its own files.

## Run it

```sh
node serve.ts
# open http://localhost:8080 — or open game/index.html from any static server
```

Controls: **← →** / **A D** move · **SPACE / ↑** jump (twice to flap) ·
**↓ / S** slide · click the canvas to flap · **P** pause · **M** mute ·
**R** restart.
